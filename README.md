# Mental Health Dashboard

Welcome to the **Mental Health Dashboard** repository! This project features a comprehensive Power BI dashboard aimed at analyzing mental health trends, specifically focusing on student depression and its correlation with various academic and lifestyle factors.

## Overview

The goal of this dashboard is to provide insights into mental wellness and potential triggers for depression among students and professionals. By analyzing data related to academic pressure, work habits, and lifestyle choices, this interactive dashboard helps stakeholders identify patterns and correlations that affect mental health.

## Project Contents

This repository contains the following key files:

- **`Powrd.pbix`**: The main Power BI dashboard file containing interactive visualizations, data models, and analytical reports.
- **`student_depression_dataset.csv`**: The primary dataset powering the dashboard. It contains diverse demographic and lifestyle metrics such as:
  - Demographic info: Age, Gender, City, Profession, Degree
  - Mental health indicators: Family History of Mental Illness, Suicidal thoughts, Depression
  - Pressures & Stress: Academic Pressure, Work Pressure, Financial Stress
  - Lifestyle factors: Sleep Duration, Dietary Habits, Work/Study Hours
  - Satisfaction metrics: CGPA, Study Satisfaction, Job Satisfaction
- **`Dashboard_Report.docx`**: A detailed report providing an in-depth summary, insights, and findings derived from the dashboard analysis.

## Features of the Dashboard

- **Demographic Analysis**: Understand how depression rates vary across different age groups, genders, and locations.
- **Pressure and Stress Tracking**: Analyze the impact of academic pressure, financial stress, and work/study hours on overall mental well-being.
- **Lifestyle Correlations**: Investigate how sleep duration and dietary habits correlate with the likelihood of experiencing depression.
- **Academic Performance Link**: See how CGPA and study satisfaction interact with mental health statuses.

## Getting Started

To view and interact with the dashboard:

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/developeranil65/mental-health-dashboard.git
   ```
2. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) if you haven't already.
3. Open the `Powrd.pbix` file using Power BI Desktop.
4. Refresh the data if necessary and explore the interactive visuals!

## Data Source

The insights are driven by the `student_depression_dataset.csv`. All data used in this project is for analytical and educational purposes, helping to shed light on important mental health issues.
